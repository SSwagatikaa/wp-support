# Slow Website Troubleshooting

## Symptoms

- Slow admin dashboard
- Long page load times
- High CPU usage

## Common Causes

- Heavy plugins
- Unoptimized images
- Poor hosting
- Database bloat
- No caching

## Optimization Steps

1. Enable caching
2. Compress images
3. Remove unused plugins
4. Optimize database
5. Use CDN
6. Update PHP version
