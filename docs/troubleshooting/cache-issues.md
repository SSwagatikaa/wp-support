# Cache Related Issues

## Common Symptoms

- Changes not visible
- Broken layouts
- Checkout issues
- Old pages loading

## Common Causes

- Browser cache
- Plugin cache conflicts
- CDN cache
- Server-side caching

## Troubleshooting

1. Clear browser cache
2. Purge plugin cache
3. Clear CDN cache
4. Disable cache plugins temporarily
5. Test in incognito mode
